# WorldRace

Three.js + TypeScript baseline for the streaming world PoC.

## Scripts
- `npm run dev`: start local dev server.
- `npm run build`: production build.
- `npm run preview`: preview production build locally.
- `npm run typecheck`: TypeScript type checks.
- `npm run lint`: ESLint checks.
- `npm run format`: Prettier write.
- `npm run format:check`: Prettier check mode.

## Notes
- GitHub Pages deploy is handled via `.github/workflows/deploy-pages.yml`.
- OSM attribution page lives at `public/attribution/osm.html`.
